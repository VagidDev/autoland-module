# Desktop App `Autoland` (Pet Project)

## 📌 Описание
Это учебный **desktop-проект на Java**, созданный для практики применения принципов **SOLID**.  
Приложение реализовано с использованием **JavaFX** (UI), **Hibernate** (работа с БД), а также частично покрыто тестами с помощью **JUnit**.  

Основные возможности:
- 👤 Работа с аккаунтами пользователей и админской панелью  
- 📊 MVC-архитектура  
- 🛠 Многомодульная структура проекта  
- ✅ Валидация объектов с учетом принципов SOLID  

⚠️ Пароли пока **не шифруются** — проект носит учебный характер.  

---

## 🏗️ Технологии
- **Java 21+**
- **JavaFX** — графический интерфейс  
- **Hibernate ORM** — работа с базой данных  
- **JUnit 5** — модульное тестирование  
- **Maven** — управление зависимостями и сборкой  

---

## 📂 Структура проекта
- `model` — бизнес-логика и работа с сущностями (Hibernate)  
- `view` — JavaFX интерфейс  
- `controller` — логика управления (MVC)  
- `tests` — модульные тесты (JUnit)  

---

## 🚀 Запуск проекта
1. Клонировать репозиторий:
   ```bash 
    git clone https://github.com/VagidDev/autoland-module.git
    ```

2. Перейти в директорию проекта:

   ```bash
   cd autoland-module/
   ```

3. Собрать проект с помощью Maven:
   ```bash
   mvn clean install
   ```

4. Запустить приложение:
   ```bash
   mvn javafx:run
   ```
5. Также есть скрипт, с помощью которого можно запустить проект
   ```bash
   ./start.sh
   ```
- PS: для запуска через скрипт необходимо в скрипте указать путь к библиотекам JavaFX

---
